\section{Objective}
The objective of this lab is to develop an open-ended full-stack project using the learned frontend and backend technologies. Specifically, the task is to build a simplified version of Amazon (Nova E-Commerce), a full-stack e-commerce web application. This encompasses implementing product listings, adding products, updating stock, removing listings, user authentication, search/filtering, and a complete shopping cart checkout flow.

\section{Introduction}
Amazon.com serves as an excellent reference for a full-stack application as it demonstrates nearly every core concept in one place. In this lab, we build a platform named "Nova," which allows sellers (Admins) to list products and customers to browse, search, add items to a cart, and place orders. The application is built using the MERN stack (MongoDB, Express.js, React, Node.js).

\subsection{Core Features Implemented}
\begin{itemize}
    \item \textbf{User Authentication:} Secure registration and login using JWT (JSON Web Tokens) and bcrypt for password hashing.
    \item \textbf{Product Management:} Full CRUD operations for products restricted to admin users.
    \item \textbf{Shopping Cart:} Context API-based cart management allowing users to add, update, and remove items.
    \item \textbf{Order Processing:} Checkout flow mapping cart items to order history, along with stock decrementing.
    \item \textbf{Search \& Filtering:} Frontend UI for browsing products by category and search terms.
    \item \textbf{UI/UX Enhancements:} Implementation of modern design elements like glassmorphism, star ratings, and responsive layouts using Tailwind CSS.
\end{itemize}

% =========================================================
% SYSTEM ARCHITECTURE
% =========================================================
\section{System Architecture}
The application follows a standard three-tier architecture:

\begin{enumerate}
    \item \textbf{Frontend (Client):} Built with React (using Vite), TypeScript, and Tailwind CSS. State management is handled via React Context API (AuthContext, CartContext) and React Query for API data fetching.
    \item \textbf{Backend (Server):} Developed using Node.js and Express.js, featuring RESTful API routes, validation middlewares, and error handling.
    \item \textbf{Database:} MongoDB with Mongoose ODM for defining schemas (User, Product, Order).
\end{enumerate}

\section{Implementation Details}
Below are key aspects of the implementation required to fulfill the lab requirements.

\subsection{Database Schema and Models}
The MongoDB schema defines three main entities. The User schema incorporates roles to distinguish between regular customers and administrators.

\begin{lstlisting}[language=JavaScript]
// server/models/User.js snippet
const userSchema = new mongoose.Schema({
    name: { type: String, required: true },
    email: { type: String, required: true, unique: true },
    password: { type: String, required: true, select: false },
    role: { type: String, enum: ["customer", "admin"], default: "customer" },
});
\end{lstlisting}

\subsection{Authentication and Authorization}
Protected routes and admin-only routes are secured via JWT middleware.

\begin{lstlisting}[language=JavaScript]
// server/middleware/authMiddleware.js snippet
export const adminOnly = (req, res, next) => {
  if (req.user && req.user.role === "admin") {
    next();
  } else {
    res.status(403);
    throw new Error("Not authorized as an admin");
  }
};
\end{lstlisting}
